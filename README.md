# AG2 | Inatel 2026.2

Classificação do canal de vendas (HoReCa ou Retail) de clientes de um atacadista, com Decision Tree (scikit-learn).

Autoras: [Bruna Magalhães](https://github.com/BrunaDev) e Lilyan Oliveira

## Como rodar
1. `pip install -r requirements.txt`
2. Abrir `ag002.ipynb` (Jupyter ou Colab, com `wholesale.csv` na mesma pasta) e executar as células em ordem.

## Arquivos
- `ag002.ipynb`: notebook com todas as etapas
- `wholesale.csv`: dataset pré-processado
- `modelo_classificacao.pkl`: modelo treinado
